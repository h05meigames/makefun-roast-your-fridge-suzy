One line roasting my fridge, written by `main.ts` to `/output/entry.txt`:

> My fridge hums like it pays rent, but its crisper drawer is a morgue where vegetables go to give up on being salad.

## Run

```sh
node main.ts
```

The program writes exactly one line (115 characters, within the 200-character gate) to `/output/entry.txt`. It is deterministic: every run writes the same line.
